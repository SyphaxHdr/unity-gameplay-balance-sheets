## Purpose

Gameplay Balance Sheets is a Unity Editor tool that helps developers and game designers create RPG-style gameplay balance sheets.

The documentation explains:

- what the tool is used for
- how reference sheets work
- how designer variants work
- how to apply and validate sheets
- how settings are stored
- what should or should not be committed to Git
